03 · Plate

A magazine about your machine. Black ground, ivory paper, one ultramarine used for nothing except the marker and the page you are on. The manual's own numbering is set as display type — the page number is the largest object on the reader because the page number is the answer. Serif for the manual's words, grotesk for the machine's. Different because it has no cards, no chrome and no second colour: the layout is a grid of hairlines and the photography carries the weight.

3D step

The render is inverted to a white ghost on black and sits inside the grid with no panel and no controls bar; the chapter numeral (13) is set at 112 px behind it in near-black, so the model floats over its own chapter. Nothing is tinted. The chosen part is a single 14 px ultramarine dot with a soft ring — the only colour on the screen — and the caption below it is set in serif, like a plate caption: Front brake · p. 84.

Marker

A 24% ultramarine wash with a solid 2 px ultramarine rule under each marked band, drawn L→R in 240 ms, 55 ms apart. It reads as an editor's underline rather than a highlighter, and it is the only place blue appears on the sheet, so the eye lands there before it reads a word.

Risk

Editorial restraint at 390 px is unforgiving: one wrong line length and it looks empty rather than composed. It is also the coldest of the five — beautiful in a portfolio, distant in a garage.
